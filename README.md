# Junescript
## The kizzy-june programming language 👍
Junescript is a programming language based on Java made to be easy.
### Installation
> Download the jarfile in [Releases](https://github.com/kizzy-june/junescript/releases)
>
> View the syntax @ [INSTRUCTIONS.txt](https://raw.githubusercontent.com/kizzy-june/junescript/refs/heads/master/INSTRUCTIONS.txt)
>
> Make a file with the .junescript file extension and make sure it's in the same directory as your jarfile, then simply run the jar!
